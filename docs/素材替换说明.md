# 素材替换说明

## 本地预览

首次运行 `npm install`，随后 `npm run dev`，打开 http://localhost:5173 。不要直接双击 HTML，内容使用 ES 模块和独立路由，需要 HTTP 服务。

`npm run check` 检查 JavaScript 语法；`npm run build` 输出 `dist/`。构建复制本地 model-viewer 依赖，不加载远程脚本。

## 内容入口

所有文案、联系方式、经历、项目和素材路径在根目录 `data.js`。`site` 管理全站，`projects` 管理作品，`experiments` 管理实验。

当前四个作品和两个实验是明确标记的模板，没有真实作品数据。原有 `项目图片/`、证件照和 PDF 保留在原处，没有自动纳入新站。

## 图片

把文件放进 `public/media/projects/project-01/images/`，网页地址写作 `/media/projects/project-01/images/你的文件.webp`。**仅放入文件不会新增作品，需要更新配置。**

图片对象示例：

```js
{ src: '/media/projects/project-01/images/cover.webp',
  alt: '准确描述画面内容', caption: '真实图注',
  aspectRatio: '4/3', fit: 'contain', position: 'center' }
```

`fit` 可用 `cover` 或 `contain`；`position` 可写 `50% 40%`。封面存入项目的 `cover`，详情图片依序写入 `gallery` 数组。壁纸用真实原始比例，局部细节推荐 `contain`。路径为空或加载失败时显示占位，不出现破图。图片详情可点击放大，Esc 关闭并回到原按钮。

## 新增、删减与排序

当前 `projects` 用 Array.from 生成空项目。补充内容时可以改成显式数组：

```js
export const projects = [{
  id: 'project-01', slug: 'project-01', status: 'published',
  title: '你的真实项目名', year: '真实年份',
  category: ['实际媒介'], role: ['实际职责'], summary: '项目背景',
  contribution: ['你的具体贡献'], credits: ['真实署名'], awards: [],
  cover: {src: '/media/projects/project-01/images/cover.webp', alt: '封面描述', aspectRatio: '4/3', fit: 'contain', position: 'center'},
  gallery: [], model: {src: null, poster: null, autoRotate: false}
}];
```

数组顺序即展示顺序；删除条目即移除项目；`unpublished: true` 隐藏未核对条目。slug 必须唯一，只使用英文字母、数字和短横线。新增后再次构建，会自动输出对应 `/work/slug/index.html`，支持普通静态托管直接访问。

`status: 'placeholder'` 显示模板标记，真实内容补齐后改为 `published`。实验系列使用相同字段，在 `experiments` 中编辑，说明实际 AI 生成、筛选和后期分工。

## 首屏图片、视频和 GLB

当前首屏使用 `site.hero.relief` 的雾气浮雕背景，图片配置是 `/media/hero/images/myth-relief-v1.png`。此前首屏 image / video / model 字段保留但暂不启用；下述模型说明适用于作品详情。交互细节见 `交互设计说明.md`。

图片采用上述对象，视频写 `video: '/media/hero/videos/你的文件.mp4'`，封面用 `hero.image`。视频静音、内联、点击播放；详情 gallery 可添加 `{type:'video', src:'...', poster:'...', caption:'...'}`。

模型示例：

```js
model: {
 src: '/media/projects/project-01/models/你的模型.glb',
 poster: '/media/projects/project-01/images/model-cover.webp',
 alt: '模型描述', cameraOrbit: '30deg 75deg 105%',
 fieldOfView: '30deg', minCameraOrbit: 'auto auto 50%',
 maxCameraOrbit: 'auto auto 200%', autoRotate: false,
 environmentImage: null
}
```

GLB 推荐打包纹理。首屏或详情一页只展示一个实时模型。所有设备默认先显示封面，点击“查看 3D”才加载模型依赖与文件。支持恢复视角、停用交互，配置自动旋转时支持暂停；离开视口停止旋转。尊重减少动态效果偏好。空路径不请求模型；加载失败或超时保留封面。

相机参数含义见 [model-viewer 官方文档](https://modelviewer.dev/docs/)。真实模型放入后需验证朝向、材质、缩放范围及移动端手势，不保证所有设备都能流畅运行大模型。

## 联系与 CV

`site.email` 填真实邮箱；`site.socialUrl` 填确认过的小红书主页 URL；`site.account` 是可复制账号。留空不产生无效入口。

把实际 PDF 放入 `public/media/cv/` 后，在 `site.cvFile` 写入 `/media/cv/文件名.pdf`，才显示下载。请先检查文件确实存在。

未核对奖项、品牌关系、学校专业名称、语言和账号数据保留在配置内，unpublished 或 internalNote 字段不会渲染。根据证书核对后再启用。

## 路由与托管

开发服务器支持 `/work/:slug` 的刷新。`dist` 内每个已配置项目有自己的 HTML 入口，托管时部署整个 dist 目录，路径以网站根目录 `/` 为基准。没有公开发布或连接外部服务。

## 验证范围

真实图片放大、失败图片降级、GLB 成功/失败/触摸交互仍需用对应素材做最终浏览器验收。390 / 768 / 1440 的断点样式已实现，精确尺寸截图与溢出检查以浏览器实际测试为准。
