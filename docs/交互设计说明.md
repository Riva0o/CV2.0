# 雾气与浮雕：交互设计

## 参考提取

参考：[Victor Silva — Studio](https://victorsilva.work/work/studio)。页面读取工具无法打开该站，浏览器扩展连接也异常；通过 HTTPS 读取公开 HTML 及其 main / idle 脚本完成代码层面的核对，未声称完成动态目视验证。

公开脚本中的线条交互使用 SVG path：检测鼠标是否穿过线的上下两侧，随鼠标拉弯，达到约 20px 拉动范围后释放，以 elastic.out 弹性回位。另有文字 line-swap 悬停动画、作品展开 / 关闭状态与滚动展示逻辑。本站重新实现同类反馈，未复制该站代码、作品、字体或整页切换机制。

本站使用原生滚动，不添加参考站中的声音或强制页面切换。

## 当前实现

- 顶部导航：Project / Axis wallpaper / About / Contact。CV 内容仍保留在页面下部，仅去掉顶部 CV 导航。
- 首屏取消左右图文布局，使用整幅汉白玉浮雕底图、纯色 Canvas 雾层与一条居中的小字号文字。
- 鼠标轨迹擦除带渐变的雾层；离开后雾气缓慢回填。Canvas 像素密度限制为 1.5，离开视口停止更新。
- “揭开浮雕”按钮支持键盘与触屏，完整展示 / 恢复雾层。
- Studio 介绍位于首屏后的留白段落，随滚动从淡到清晰，保持可读而非完全隐藏。
- 栏目分隔线在鼠标穿过时被拉弯，释放后用阻尼弹簧回弹。
- 作品悬停增加微幅倾斜、局部光感和小箭头反馈。
- 减少动态效果模式直接显示浮雕、完整叙事，并关闭线条和悬停运动。
- 切换详情页时释放监听器、观察器及动画帧；背景加载失败时保留文字入口。

## 配置

底图配置在 `data.js` 的 `site.hero.relief`。素材为 `public/media/hero/images/myth-relief-v1.png`。这是一张生成的界面视觉背景，标记为“AI 生成 · 界面视觉”，不代表用户真实作品。

`interactions.js` 管理雾层、琴弦和叙事。雾气回填时间常数为 3300ms；线条最大拉动约 14px，弹簧刚度 210、阻尼 15。文字尺寸与留白在 styles.css 的 Immersive edition 段落调整。

当前首屏使用雾气交互背景，原 hero.image / video / model 配置保留但不在该首屏启用；作品详情的 GLB 展示仍正常使用。

## 文字与分隔线反馈更新

标题、项目名称和叙事短句支持局部文字上浮约 2px，并变为青绿色；正文提供轻微颜色反馈，导航与文本链接有细线展开反馈。键盘焦点仍保留可见边框。触屏不触发悬停运动，减少动态效果模式关闭文字位移。

线条覆盖栏目、CV 条目、详情摘要与联系段落的分隔线。鼠标穿过线条时轻微拉弯，释放后快速衰减回弹；穿过正好位于线上的坐标也会正确响应。语法检查、构建及已有交互事件检查通过，本次未完成浏览器动画目视验收。
