# Protoaxis Studio — Portfolio 2.0

从零重做的个人数字设计作品档案。纯色雾层揭开中国神话汉白玉浮雕；小字号叙事随滚动展开，分隔线支持琴弦回弹。顶部导航为 Project / Axis wallpaper / About / Contact；详情页支持直接访问。

```sh
npm install
npm run dev
```

预览：http://localhost:5173

```sh
npm run check
npm run build
```

构建输出到 `dist/`。文案和素材集中配置在 `data.js`；替换方式见 [素材替换说明](docs/素材替换说明.md)。原有素材保留，不会自动作为正式作品展示。本次仅本地制作。

交互实现、参考提取与图像生成记录见 [交互设计说明](docs/交互设计说明.md)。
